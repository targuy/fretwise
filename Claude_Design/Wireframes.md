# Wireframes — FretWise

All wireframes use ASCII art. Characters used:
- `█` block / opaque element
- `─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼` box-drawing lines
- `●` active element / playhead dot
- `[ ]` button, `( )` radio, `[x]` checked, `< >` combo
