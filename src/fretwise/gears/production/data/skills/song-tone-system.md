# Conception d’un son — Méthode universelle

Méthode indépendante de tout matériel pour **analyser**, **déduire** et **reconstruire** un son (pédales → ampli → cab/IR → guitare) afin d’obtenir la meilleure configuration possible pour une **chanson**, un **artiste** ou un **genre**.

---

## 0) Principe clé : le son = **source + chaîne + contexte**

1. **Source** : guitare (micros, potentiomètres, attaque), cordes, accordage, médiator, technique.
2. **Chaîne** : pédales/FX → ampli (préamp) → power amp → baffle + HP → micro(s) → mix.
3. **Contexte** : volume réel, pièce, mix, production (EQ/comp), backing track.

> **Règle** : si tu copies “les réglages exacts” sans copier le **baffle/IR** (et souvent la **guitare/micros**), tu n’auras pas le même résultat.
> 

---

## 1) Étape A — Définir la cible (morceau / artiste / période)

### A1. Choisir un *référentiel audio*

- Studio (album) ou live (tournée) ?
- Quelle version exacte (année, remaster, prise live) ?
- Segment ciblé (couplet clean, refrain crunch, solo) ?

### A2. Décrire le son en 10 secondes

Remplis ces curseurs :

- Gain : clean → edge → crunch → lead → hi-gain
- Brillance : sombre ↔ brillant
- Médiums : creusé ↔ mid-forward
- Grave : tight ↔ large/boomy
- Grain : doux ↔ agressif / “fizzy”
- Image : mono ↔ large (stéréo)
- Effets : (liste) + niveau (subtil / évident)

### A3. Identifier l’ADN “impossible à tricher”

- Type de **micros** (single / humbucker / P90 / actifs)
- Type d’**ampli** (Fender / Vox / Marshall / Mesa / Orange / Hiwatt / boutique…)
- Type de **baffle & HP** (open-back vs closed-back, Greenback vs V30, etc.)
- **Production** (double tracking, EQ agressif, compression, room mic…)

---

## 2) Étape B — Trouver le *rig d’origine* (ou la meilleure hypothèse)

### B1. Sources de recherche (rapides)

- Equipboard (rigs par artiste/période)
- Premier Guitar “Rig Rundown”
- Interviews tech (Guitar World, [Guitar.com](http://Guitar.com), forums spécialisés)
- Setlists + photos de tournée
- Vidéos “isolated tracks” / re-amp / sessions studio quand dispo

### B2. Sortie attendue

Une liste **priorisée** :

1. Guitare(s) / micros
2. Ampli(s) (modèle + canal)
3. Baffle(s) + HP
4. Pédales “signature” (OD/fuzz/boost/mod/delay/reverb)
5. Détails : accordage, cordes, capos, volume/tone, pick, etc.

<aside>
🔎

Astuce : vise d’abord le **couple ampli + baffle/HP**. C’est là que se joue 70% du timbre.

</aside>

---

## 3) Étape C — Traduire en **blocs fonctionnels** (peu importe la marque)

Au lieu de “telle pédale”, pense “tel rôle” :

### C1. Pré-gain (avant l’ampli)

- **Noise gate** (si hi-gain)
- **Comp** (clean/funk/attaque)
- **Boost** (volume ou gain)
- **OD type TS** (resserrer les basses, mid-hump)
- **OD transparent** (gain + headroom)
- **Fuzz** (germanium/silicon, très dépendant de la guitare)

### C2. Cœur : ampli / préamp

- Clean : Fender/JC-120/Matchless…
- Crunch : Vox/Marshall/Plexi…
- Hi-gain : Mesa/5150/ENGL/Diezel…

### C3. Baffle / IR (obligatoire)

- Open-back 1x12/2x12 : clean, edge, vintage
- Closed-back 4x12 : punch, rock/metal
- HP : Greenback (médiums doux), V30 (médiums agressifs), Alnico (chime), etc.

### C4. Post-gain (après l’ampli)

- **EQ post** : sculpter (high-pass/low-pass, notch fizz)
- **Modulation** : chorus/phaser/flanger/tremolo
- **Delay** : analog/tape/digital, tempo, mix
- **Reverb** : spring/plate/hall/shimmer
- **Doubler / widen** : pour sons stéréo “studio”

---

## 4) Étape D — Construire la recette (workflow)

## D1. Ordre de chaîne recommandé

```
Guitare
→ (Gate)
→ (Comp / Wah / Pitch)
→ (OD / Dist / Fuzz)
→ Ampli / Preamp
→ Cab / IR
→ EQ post (surtout hi-gain)
→ Mod
→ Delay
→ Reverb
→ Sortie (FRFR / casque / sono / interface)
```

## D2. Méthode de réglage (dans l’ordre)

1. **IR/Cab** : choisis un IR “proche” du rig (ex: 4x12 V30).
2. **Ampli** : règle gain/eq “neutre” (pas extrême).
3. **OD/Boost** : ajoute seulement si nécessaire (tight, sustain).
4. **EQ post** : coupe ce qui gêne :
    - High-pass typique : 70–120 Hz (selon accordage)
    - Low-pass typique : 6–10 kHz (selon fizz)
    - Notch : 3–4 kHz si agressif, 250–400 Hz si boueux
5. **Effets temps** : delay/reverb au **tempo** et au **niveau** juste (souvent moins que ce qu’on croit).
6. **Level matching** : même volume perçu que tes autres sons.

---

## 5) Étape E — “Validation mix” (le vrai test)

- Test **solo** (plaisant ?)
- Test **dans un backing track** (coupe dans le mix ?)
- Test **à volume réaliste** (FRFR/enceintes)
- Ajuste : médiums (présence) avant de toucher au gain

<aside>
✅

Un son “album” est souvent **moins saturé** et **plus médium** que ce qu’on imagine.

</aside>

## 6) Recettes — par genre (guitare)

Objectif : une bibliothèque d’**archétypes** par genre. Chaque recette indique **guitare / accordage**, **ampli**, **cab/IR**, **pédales/FX clés**, et **notes de mix**.  

À utiliser comme base, puis affiner avec les étapes B (rig d’origine) et D (réglage).

<aside>
⚠️

“Tous les genres” = en pratique **tous les grands genres guitare** et leurs sous-familles récurrentes. Les micro-scènes (ex : “shoegaze blackgaze 2016”) se mappent à ces archétypes (ex : shoegaze = fuzz + reverb + modulation + murs stéréo).

</aside>

---

### 6.1 Clean / Pop / Funk / Reggae

**Clean US “Blackface”** (pop, funk, country, reggae)

- Guitare : single coils / positions 2-4 ; attaque nette
- Ampli : Fender-style clean
- Cab/IR : 1x12–2x12 open-back (Jensen/C12K)
- FX : comp (option) + spring/room ; delay slap si besoin
- Notes : mids présents, pas trop de bas

**Reggae skank**

- Guitare : single coils ; palm mute léger
- Ampli : clean très headroom (Fender/Twin) ou JC-120
- Cab/IR : open-back
- FX : spring légère + éventuellement phaser/chorus très subtil
- Notes : coupe bas (HPF), privilégie l’attaque

---

### 6.2 Indie / Britpop / Jangle / Alternative

**Clean UK “Chime”** (jangle)

- Guitare : single coils / P90 / Rickenbacker-style
- Ampli : Vox-style / Matchless
- Cab/IR : 2x12 Alnico Blue
- FX : tremolo/chorus subtil ; slapback
- Notes : brillance contrôlée (LPF si besoin)

**Indie rock crunchy**

- Guitare : single coils/P90
- Ampli : Vox/Marshall low gain
- Cab/IR : 2x12 open-back ou 4x12 Greenback
- FX : OD low gain + plate/room
- Notes : moins de gain, plus de mids

---

### 6.3 Blues / Blues-rock / Soul

**Blues clean-to-crunch**

- Guitare : Strat/Tele (single) ou humbuckers doux
- Ampli : Fender pushed / Bassman / Tweed / Dumble-ish
- Cab/IR : 1x12–2x12 open-back
- FX : OD transparent / TS léger ; spring ; delay court (option)
- Notes : dynamique au volume guitare

**Chicago / Texas blues (SRV-ish)**

- Guitare : Strat, tirant plus fort
- Ampli : Fender-style fort + OD type TS
- Cab/IR : 4x10 (Super Reverb) ou 2x12
- FX : TS (drive bas, level haut), spring
- Notes : mids, tight bas

---

### 6.4 Classic rock / Hard rock / Arena

**Crunch Plexi (70s)**

- Guitare : humbuckers/P90
- Ampli : Plexi/JMP
- Cab/IR : 4x12 Greenback (ou G12H30 pour plus de bas)
- FX : quasi rien ; slapback/plate discret
- Notes : gain modéré, attaque

**80s hard rock / “hot-rodded”**

- Guitare : humbuckers
- Ampli : JCM800 / Friedman / mod Marshall
- Cab/IR : 4x12 V30 ou Greenback selon goût
- FX : boost/OD léger + delay lead + plate
- Notes : mids pour percer

---

### 6.5 Metal — thrash / heavy / death / modern / djent

**Metal “tight” moderne (djent/metalcore)**

- Guitare : humbuckers ; souvent 7/8 cordes ; drop
- Ampli : 5150 / ENGL / Diezel / Revv
- Cab/IR : 4x12 V30 (Mesa/Orange/ENGL)
- FX : gate + TS-style boost + EQ post + (reverb très courte)
- Notes : HPF 80–120 Hz, LPF 7–9 kHz, contrôle 3–4 kHz

**Thrash / old-school**

- Guitare : humbuckers ; accordage standard/Eb
- Ampli : JCM800 / Mesa Mark
- Cab/IR : 4x12 (Greenback/V30)
- FX : OD léger + gate modéré
- Notes : attaque, médiums, moins de bas

**Death metal (gain dense)**

- Ampli : 5150 / Rectifier / ENGL
- Cab/IR : V30
- FX : gate + EQ post (notch boue 250–400 Hz)

---

### 6.6 Stoner / Doom / Sludge

**Stoner fuzz wall**

- Guitare : humbuckers ; accordages bas
- Ampli : Orange / Matamp / Sunn-style
- Cab/IR : 4x12 (V30 ou modèles plus “gros”)
- FX : Big Muff / fuzz + éventuellement EQ ; reverb faible
- Notes : garder des mids (éviter scoop excessif)

---

### 6.7 Punk / Pop-punk / Hardcore

**Punk rythmique**

- Guitare : humbuckers (ou P90)
- Ampli : Marshall/5150 low-mid gain
- Cab/IR : 4x12
- FX : disto simple, peu d’effets
- Notes : tight bas, mids, volume constant

---

### 6.8 Grunge / 90s alt

**Grunge fuzz/dist**

- Guitare : humbuckers
- Ampli : Marshall/Mesa/solid-state selon cible
- Cab/IR : 4x12
- FX : DS-1/DS-2/RAT/Muff ; chorus (option)
- Notes : parfois “messy” assumé ; attention au bas

---

### 6.9 Shoegaze / Dream pop / Post-rock / Ambient

**Shoegaze “wash”**

- Guitare : single ou humbuckers ; accords
- Ampli : clean headroom (Fender/JC-120) ou Vox clean
- Cab/IR : open-back ou 2x12
- FX : fuzz/OD + chorus + reverb longue + delay ; stéréo si possible
- Notes : EQ post pour éviter boue ; HPF ~100 Hz

**Post-rock (delay empilé)**

- Ampli : clean
- FX : delay multi (subdivisions) + reverb hall/shimmer
- Notes : tempo, niveaux d’effets dosés

---

### 6.10 Jazz / Neo-soul / R&B

**Jazz warm clean**

- Guitare : humbuckers (tone baissé)
- Ampli : clean rond (Fender, Polytone, JC-120 doux)
- Cab/IR : 1x12 open-back
- FX : comp léger (option) + reverb room
- Notes : peu de haut, dynamique

**Neo-soul**

- Guitare : single coils / positions intermédiaires
- Ampli : clean
- FX : comp + chorus/vibrato subtil + delay léger
- Notes : attaque douce, stéréo si possible

---

### 6.11 Country / Americana

**Country clean + slap**

- Guitare : Tele (bridge), comp
- Ampli : Fender clean
- Cab/IR : 1x12–2x12 open-back
- FX : comp + slapback + spring
- Notes : twang, attaque, pas de bas

---

### 6.12 Surf / Rockabilly

**Surf**

- Ampli : Fender clean
- Cab/IR : open-back
- FX : spring “drip” + tremolo

**Rockabilly**

- Ampli : tweed/blackface
- FX : slapback tape/analog

---

### 6.13 Metal “classic” / Prog / Lead moderne

**Lead “Smooth” (Dumble/Boogie)**

- Guitare : humbuckers
- Ampli : Dumble/Boogie-style
- Cab/IR : 1x12 / 2x12
- FX : delay court + plate
- Notes : mids riches, haut doux

**Prog moderne (précis)**

- Ampli : Mesa Mark / Diezel / 5150III
- Cab/IR : V30
- FX : gate modéré + delay stéréo + reverb courte

---

### 6.14 Acoustic / Folk (avec électro-acoustique ou sim)

**Acoustic “studio”**

- Source : électro-acoustique / sim acoustique
- Chaîne : comp léger → EQ (HPF) → reverb room
- Notes : éviter bas, ajouter air

---

### 6.15 Latin / Bossa / Gypsy (repères)

**Bossa / latin clean**

- Ampli : clean
- FX : reverb room légère
- Notes : attaque douce, médiums contrôlés

**Gypsy jazz**

- Guitare : type Selmer (si possible)
- Ampli : très clean / micro + EQ
- Notes : très peu d’effets, focus attaque

---

### 6.16 Synth / FX guitar (genre “sound design”)

**Guitar → synth textures**

- Ampli : clean
- FX : pitch + filter + reverb/delay + comp
- Notes : tracking = jeu propre ; HPF/LPF pour “mix”

## 8) Checklist “Trouver la meilleure config”

- [ ]  J’ai identifié la **période** et la **version** (studio vs live)
- [ ]  J’ai le **couple ampli + cab/IR** cohérent
- [ ]  J’ai choisi la guitare/micros les plus proches
- [ ]  Je règle **moins de gain** et **plus de médiums** si ça ne coupe pas
- [ ]  Je valide **dans un backing track**
- [ ]  Je documente la recette + variantes

## 10.3 Pédales — référentiel (types + marques/modèles)

**Lecture** : comme pour les amplis/cabs, on pense en **familles** (fonction + couleur) puis on choisit un modèle précis (hardware, multi-effets, plugin).

<aside>
🧠

“Exhaustif” au sens *référentiel utile* : couvrir **tous les types de pédales** et, dans chaque type, les **modèles emblématiques** (ceux qui servent de standard / de base de modélisation / de référence culturelle).

</aside>

---

### 10.3.1 Dynamique & utilitaires

- Boost / Preamp / Buffer
    
    **Rôle** : pousser un ampli, relever le niveau, ajouter du “sparkle”, bufferiser un board.
    
    - **EP Booster-style** *(préamp “Echoplex”)* : **léger bump médiums/haut-médiums**, sensation “3D”, très bon *always-on* → Xotic EP Booster, ClinchFX EP-Pre, J. Rockett Archer Boost (boost mode)
    - **Clean boost** *(niveau sans trop colorer)* : sert à **taper plus fort** l’entrée d’un ampli/OD (plus de sustain/drive) → MXR Micro Amp, TC Electronic Spark Booster, Keeley Katana, Electro-Harmonix LPB-1
    - **Preamp/Color** *(couleur d’étage de gain / console)* : ajoute **harmoniques** + légère compression, peut “salir” un clean → Benson Preamp, Hudson Broadcast, JHS Colour Box, API/console-style (plugins)
    - **Buffers** *(impédance)* : **aigus préservés**, moins de perte avec longs câbles/board → Boss (buffers intégrés), TC BonaFide Buffer, JHS Little Black Buffer
- Compresseurs
    
    **Familles** :
    
    - **Ross/Dyna Comp** *(squish)* : attaque “snap”, sustain, peut **pomper** (funk/country) → MXR Dyna Comp, Keeley Compressor Plus, Wampler Ego
    - **Opto / studio** *(plus naturel)* : compression **progressive**, moins d’artefacts, excellent en clean/rythmique → Diamond Compressor, Origin Effects Cali76 (FET/studio), Becos CompIQ
    - **Multi-band / moderne** : contrôle propre sans trop écraser, utile sur sons complexes (accords + FX) → Boss CP-1X, TC HyperGravity
- Noise Gate / Suppressor
    
    **Signature** : réduit le souffle, mais peut **couper le sustain** si réglé trop agressif (surtout en lead).
    
    - Boss NS-2 *(classique, loop send/return)*
    - ISP Decimator II / G-String *(très transparent, efficace hi-gain)*
    - TC Sentry *(modes + TonePrint, polyvalent)*
    - Fortin Zuul *(ultra “tight”, metal moderne)*
    - MXR Smart Gate *(simple, efficace)*
- EQ / Filtrage / Volume / Switch
    - **EQ graphique** : Boss GE-7, MXR 6/10 Band, Mesa 5-Band EQ
    - **EQ paramétrique** : Empress ParaEQ, Source Audio EQ2
    - **HPF/LPF (anti-fizz/boom)** : Broughton HPF/LPF, TC/Strymon via EQ
    - **Volume** : Ernie Ball VP Jr, Dunlop Volume (X), Boss FV-500
    - **A/B/Y & loopers** : Radial Twin-City, Lehle, Boss LS-2, JHS Switchback

### 10.3.2 Overdrive (OD) — familles & modèles

- Tube Screamer / mid-hump (serre le bas, boost lead)
    
    **Signature** : **coupe un peu de basses**, pousse les **médiums**, rend un ampli hi-gain plus **tight** (excellent en boost ; drive bas / level haut).
    
    - Ibanez TS808 *(mid-hump doux)* / TS9 *(un peu plus mordant)* / TS10 *(souvent perçu plus ouvert)*
    - Maxon OD808 / OD9 *(très proches des TS)*
    - Boss SD-1 *(clipping asymétrique → plus de “grain”)*
    - EarthQuaker Plumes *(plus d’options, peut être plus bright)*
    - JHS Moonshine, Wampler Clarksdale *(TS “étendus”, plus de headroom)*
- Klon / “transparent boost” avec mids (mythe + standard)
    
    **Signature** : boost **transparent mais “présent”**, bas ferme, médiums subtils ; excellent *always-on* ou boost de lead.
    
    - Klon Centaur *(réf : clean + “golden mids”)*
    - Electro-Harmonix Soul Food *(souvent plus bright)*
    - J. Rockett Archer (Ikon/Classic) *(très réputé, proche de l’esprit)*
    - Wampler Tumnus *(souvent plus “polished”)*
    - MXR Sugar Drive *(compact, dynamique)*
- Transparent OD (Timmy / low-gain “amp-like”)
    
    **Signature** : conserve le caractère guitare/ampli, peu de compression ; parfait pour “edge-of-breakup” et empiler plusieurs étages.
    
    - Paul Cochrane Timmy *(réf : EQ cut très utile, très “amp-like”)*
    - MXR Timmy *(version moderne du Timmy)*
    - Greer Lightspeed *(doux, très organique, excellent always-on)*
    - Boss BD-2 *(grain un peu “fuzzy” quand poussé, très musical)*
    - JHS Morning Glory *(plus bluesbreaker-like, brillant, open)*
- Bluesbreaker / “edge” british doux
    
    **Signature** : crunch doux, médiums “bois”, très bon pour épaissir sans perdre la dynamique ; empile très bien avec un boost.
    
    - Marshall Bluesbreaker *(original : référence “soft clipping” brit)*
    - JHS Morning Glory *(plus brillant / plus ouvert)*
    - Wampler Pantheon *(plus de gain et d’options)*
    - Analogman King of Tone / Prince of Tone *(référence boutique, ultra musical)*
- Dumble-ish / smooth OD
    
    **Signature** : médiums riches, haut doux, sustain “chantant”, sensation de lead fluide ; souvent moins agressif que du Marshall.
    
    - Hermida Zendrive *(référence : smooth, focus mids)*
    - Wampler Euphoria *(dumble-ish polyvalent)*
    - J. Rockett The Dude *(plus marqué, “amp-like”)*
    - Vertex Steel String / dumble-style *(plutôt clean/boost Dumble SSS selon versions)*
- Vox/Top-Boost in a box &amp; “chime OD”
    - JHS Charlie Brown / Angry Charlie (plus Marshall), mais pour Vox : **Tech 21 Liverpool**, Wampler Thirty Something, Greer Royal Velvet (plus large)

### 10.3.3 Distorsion — familles & modèles

- RAT (du OD au fuzz, mids, très polyvalent)
    
    **Signature** : mordant, médiums, va du crunch au fuzz ; le filtre permet de calmer l’agressivité (super “couteau suisse”).
    
    - ProCo RAT 2 / Whiteface RAT *(standard / vintage)*
    - JHS PackRat *(plusieurs versions/époques)*
    - Walrus Iron Horse *(RAT modernisé, plus de gain)*
    - Mooer Black Secret *(clone populaire)
- DS-1 / hard-clipping “classique”
    
    **Signature** : disto “tranchante” et compressée (hard clipping) ; souvent meilleure dans un ampli déjà crunchy.
    
    - Boss DS-1 *(standard rock 80/90s)*
    - Boss DS-2 *(Turbo : plus de mids ; Frusciante)*
    - MXR Distortion+ *(plus vintage/low gain, grain plus doux)*
- High-gain “modern distortion”
    
    **Signature** : saturation dense + compression, attaque précise ; souvent besoin d’un **HPF/LPF** ou d’un cab/IR adapté pour éviter le “fizz”.
    
    - Boss MT-2 Metal Zone *(EQ très puissant ; souvent utilisé comme préamp)*
    - Revv G3 / G4 *(gain moderne tight)*
    - Friedman BE-OD *(hot-rodded Marshall, beaucoup de gain)*
    - Suhr Riot *(grain lead moderne, mids présents)*
    - Wampler Dracarys *(metal moderne, serré)*
    - Fortin series *(metal très tight, souvent pensé pour 7/8 cordes)*
- Marshall-in-a-box (Plexi/JCM dans une pédale)
    
    **Signature** : upper-mids “Marshall”, grain rock, attaque ; peut remplacer un canal drive ou servir d’étage gain devant un clean.
    
    - Xotic SL Drive *(plexi compact, très populaire)*
    - Carl Martin Plexitone *(3 canaux/voicings, rock 80s)*
    - Wampler Plexi-Drive / Pinnacle *(Plexi vs brown sound)*
    - JHS Angry Charlie *(JCM-ish, plus moderne)*
    - MI Audio Crunch Box *(référence “MIAB”)*
    - Bogner Ecstasy Blue/Red *(voicing boutique, plus hi-gain)*

### 10.3.4 Fuzz — familles & modèles

- Fuzz Face (germanium/silicon, volume guitare crucial)
    - Dunlop Fuzz Face (FFM/Classic)
    - Analogman Sun Face
    - Fulltone ’69 / ’70 (réfs historiques)
- Tone Bender / MKI/MKII/MKIII
    
    **Signature** : fuzz british vintage, plus “nasal/mid” qu’un Muff ; super pour riffs/lead 60s/70s.
    
    - Sola Sound Tone Bender *(lignée historique)*
    - JHS Bender *(recréation moderne)*
    - Keeley Fuzz Bender *(plus de contrôle EQ)*
- Big Muff (sustain, “mur”, scooped)
    
    **Signature** : énorme sustain, parfois **médiums creusés** (scooped) → super en mur de son mais peut se perdre en mix (solution : booster les mids / choisir une version mid-forward).
    
    - EHX Big Muff Pi (NYC) *(réf “classique”)*
    - Triangle / Ram’s Head *(variantes plus vintage)*
    - Sovtek Green Russian *(plus épais dans les bas-médiums, stoner)*
    - EarthQuaker Hoof *(muff-ish, souvent plus contrôlable)*
- Octave fuzz
    
    **Signature** : fuzz + octave supérieure (souvent plus audible sur la corde de manche et avec un jeu “mono-note”) ; très Hendrix.
    
    - Roger Mayer Octavia *(référence)*
    - Dunlop JH-2S Octavio *(style Hendrix)*
    - Fulltone Octafuzz *(Octavia + fuzz face-ish)*

### 10.3.5 Modulations (pitchless)

- Chorus (CE-style, tri-chorus, etc.)
    
    **Signature** : épaissit/élargit ; CE-style = chorus “liquide” musical, tri-chorus = plus large/80s. Trop de mix = “mer”.
    
    - Boss CE-1 *(mythique, très riche)* / CE-2 *(réf)* / CE-5 *(plus propre)*
    - Electro-Harmonix Small Clone *(chorus épais, grunge/80s)*
    - MXR Analog Chorus *(chaud, simple)*
    - TC Electronic Corona *(polyvalent, TonePrint)*
    - Strymon Ola *(chorus haut de gamme, très large)*
- Phaser (Phase 90 / Small Stone)
    
    **Signature** : balayage de phase (sans delay) ; Phase 90 = “whoosh” doux, Small Stone = plus marqué ; parfait avant drive.
    
    - MXR Phase 90 / Phase 45 / Phase 100 *(classiques)*
    - Electro-Harmonix Small Stone *(plus “swirl”)*
    - Boss PH-1R / PH-2 *(plus de contrôle/modes)*
- Flanger (jet)
    
    **Signature** : chorus extrême avec “jet plane”, creux/peaks très audibles ; attention au mix (vite envahissant).
    
    - MXR M117 Flanger *(jet classique)*
    - Electro-Harmonix Electric Mistress *(plus “liquide”, Gilmour-ish)*
    - Boss BF-2 *(standard 80s)*
- Tremolo
    
    **Signature** : variation de volume ; peut être rond (bias) ou plus “haché” (opto) ; excellent sur clean/chime.
    
    - Boss TR-2 *(simple, efficace)*
    - Strymon Flint *(trem + reverb, très musical)*
    - Fulltone Supa-Trem *(opto vibe, très marqué)*
- Rotary / Univibe
    
    **Signature** : mouvement 3D ; Univibe = “chewy” psyché (Hendrix/Trower), rotary = simulation Leslie plus hi-fi.
    
    - Dunlop Uni-Vibe *(classique)*
    - Voodoo Lab Micro Vibe *(format compact)*
    - Fulltone Deja Vibe *(référence moderne)*
    - Neo Instruments Ventilator *(rotary haut de gamme)*

### 10.3.6 Time-based — Delay / Reverb / Looper

- Delay analog (BBD)
    
    **Signature** : répétitions **sombres** qui se fondent, modulation naturelle ; parfait pour “épaisseur” sans envahir.
    
    - Boss DM-2 / DM-2W *(réf, très musical)*
    - Electro-Harmonix Deluxe Memory Man *(mythique, plus “wow/flutter”)*
    - MXR Carbon Copy *(simple, dark, efficace)*
- Delay tape / echoplex / space echo
    
    **Signature** : répétitions **granuleuses**, modulation “wow/flutter”, saturation légère ; très musical en lead/ambient.
    
    - Roland RE-201 / Boss RE-2 / RE-202 *(space echo : caractère très marqué)*
    - Dunlop EP103 Echoplex *(préamp + vibe tape)*
    - Strymon El Capistan *(référence moderne tape)*
- Delay digital / studio (précis, multi)
    
    **Signature** : répétitions propres, stéréo/tempo précis, subdivisions ; idéal U2/ambient moderne et delays synchronisés.
    
    - Boss DD-3 / DD-7 / DD-8 *(classiques)* / DD-500 *(ultra complet)*
    - TC Electronic Flashback / Nova Delay *(polyvalent)*
    - Line 6 DL4 (MkI/MkII) *(standard “multi-delay”)*
    - Strymon Timeline *(référence pro, très hi-fi)*
- Reverb spring / plate / hall / shimmer
    
    **Spring** : “drip” & vintage (surf/Fender). **Plate** : dense, studio (lead). **Hall** : grande salle. **Shimmer** : octave/ambient.
    
    - Fender ’63 Reverb *(spring tank iconique)*
    - Electro-Harmonix Holy Grail *(spring/hall simple)*
    - Boss RV-6 / RV-500 *(polyvalent, moderne)*
    - Strymon BigSky *(référence ambient/qualité)*
    - Eventide Space *(textures + algos)*
    - Meris Mercury7 *(shimmer/ambient cinématique)
- Looper
    
    **Signature** : pas un “son” mais un outil : overdub, entraînement, couches ; la qualité dépend du headroom et du placement (souvent en fin de chaîne).
    
    - Boss RC-1 / RC-5 *(simples)* / RC-10R *(rythmes)*
    - TC Ditto (1/2/+) *(ultra simple)*
    - Electro-Harmonix 720 *(format pédale, pratique)*

    - Digitech Whammy *(pitch temps réel)*

    - Boss SY-1 / SY-200 *(poly, immédiat)* / SY-300 *(plus deep)*
