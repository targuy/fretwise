# Skill — Trouver le bon NAM + IR

Ce document est un **skill autosuffisant** : *comment trouver le bon couple NAM (SnapTone) + IR pour reproduire un son de chanson / genre / artiste* 

---

## 1) Le principe : “Source → Référence → Cible”

Tu ne cherches pas “un bon NAM” en général. Tu cherches :

1. **Une référence** (la piste ou le son d’un artiste)
2. **Une hypothèse** (quel ampli/cab/mic derrière ce son)
3. **Un couple NAM + IR** qui reproduit cette hypothèse
4. **Une validation A/B** (au casque/monitors) avec corrections minimales

> Objectif : obtenir *un son “dans le style”* rapidement, avec des choix reproductibles (et documentables dans Notion).
> 

---

## 2) Comprendre les 2 rôles : NAM vs IR

### NAM / SnapTone (le “préamp + poweramp + feel”)

Le NAM influence surtout :

- le **grain** (texture de saturation)
- la **dynamique** (réponse au volume/picking)
- le **voicing** général (mid focus, compression)

### IR (le “cab + micro + placement”)

L’IR influence surtout :

- la **couleur** (aigus/harsh, graves, médiums)
- la **présence** (attaque, “3–5 kHz”, intelligibilité)
- la **taille perçue** (1×12 vs 4×12)
- le côté **fizzy / smooth** sur les distos

Règle utile :

- Si ça sonne “pas le bon ampli / pas le bon grain” → touche au **NAM**
- Si ça sonne “pas la bonne enceinte / trop sombre / trop agressif” → touche à l’**IR**

---

## 3) Workflow rapide (chanson / artiste / genre)

### Étape A — Définir la cible (2 minutes)

Note ces 6 critères, même grossièrement :

1. **Niveau de gain** : Clean / Edge / Crunch / Rock / Hi-gain
2. **Focus médiums** : scooped / mid-forward
3. **Brillance** : dark / balanced / bright
4. **Tightness** (grave) : loose / tight
5. **Ambiance** : dry / room / large (reverb/delay)
6. **Pick attack** : soft / normal / très tranchant

### Étape B — Identifier “famille ampli” (hypothèse)

Utilise ces raccourcis :

- **Clean US** (funk/pop) → Fender (Deluxe/Twin), parfois JC-120
- **Chime UK** (indie) → Vox AC30
- **Crunch UK** (rock classique) → Marshall (Plexi/JCM)
- **Lead 80s/90s** → JCM800 / Soldano / Mesa Mark
- **Modern hi-gain** → 5150/EVH / Rectifier / Diezel / Revv

> Si tu hésites entre deux familles, prends les deux en parallèle et compare rapidement (A/B).
> 

### Étape C — Choisir un NAM (capture) *qui match le “feel”*

Critères de sélection d’une capture NAM :

- **Gain cohérent** avec la cible (évite de compenser +15 dB avec un OD)
- **Réponse au volume guitare** (nettoyage en baissant le volume)
- **Bruit & stabilité** (pas de souffle excessif, pas de gated étrange)
- **“Ça sonne vite”** : si tu dois sauver la capture à coups d’EQ extrême → next

Astuce : garde **2–3 captures max** par ampli (low / mid / high gain). Le reste = bruit dans ta bibliothèque.

### Étape D — Choisir l’IR (cab + micro) *qui match le mix*

#### 1) Choisir le format de cab

- **1×12 / 2×12** : plus “open”, moins de bas, souvent plus “record-ready”
- **4×12** : plus de masse, plus de bas/médiums, rock/métal typiques

#### 2) Choisir le type de HP (raccourcis)

- **V30** : moderne, présence, coupe bien dans le mix (rock/métal)
- **Greenback** : vintage, médiums musicaux (classic rock)
- **Creamback** : entre les deux (polyvalent)
- **Alnico Blue** : chime Vox, brillance “musicale”
- **Jensen / American** : clean US, haut clair, bas plus léger

#### 3) Choisir le micro/placement (si ton pack IR le propose)

- **SM57 on-axis** : attaque, présence, parfois agressif
- **SM57 off-axis** : plus doux, moins de harsh
- **R121 / ribbon** : gras, smooth, moins d’aigus
- **Blend 57+121** : standard “mix pro” (attaque + corps)

> Règle simple : d’abord **IR qui sonne** (cab/HP), puis **micro** (attaque vs douceur).
> 

### Étape E — Ajuster minimalement (ne pas “EQ pour sauver”)

Ordre conseillé (rapide et reproductible) :

1. **IR** (changer) plutôt que gros EQ
2. **Gain/Level** du NAM (petits pas)
3. **OD/Boost** (si besoin) : gain bas / level haut
4. **EQ post** léger (2–3 dB max) :
    - coupe bas (rumble) : ~70–120 Hz
    - contrôle harsh : ~3–5 kHz (petite atténuation)
    - contrôle fizz : ~7–9 kHz (petite atténuation)

## 4) Recettes “genre / artiste” (guides rapides)

> Chaque recette = point de départ. L’IR fait souvent 60% du “mix feel”.
> 

### 4.1 Clean US (pop/funk) — “clair, claquant, propre”

- **NAM** : Fender clean (Deluxe/Twin) ou JC-120
- **IR** : 1×12 Jensen / 2×12 open-back
- **Micro** : 57 off-axis ou ribbon léger
- **Effets** : comp léger, chorus subtil, room short

### 4.2 Indie / Brit chime — “AC30, brillant mais pas agressif”

- **NAM** : Vox AC30 (Top Boost / edge)
- **IR** : 2×12 Alnico Blue (ou équivalent)
- **Micro** : 57 off-axis / blend
- **Effets** : delay dotted-eighth (selon morceaux), plate reverb

### 4.3 Classic rock — “crunch Marshall”

- **NAM** : Plexi / JTM / JCM style crunch
- **IR** : 4×12 Greenback / Creamback
- **Micro** : 57 + ribbon (blend) si dispo
- **Astuce** : baisse un peu le gain, monte le level

### 4.4 Hard rock / lead 80s — “sustain, médiums”

- **NAM** : JCM800 / Soldano (gain moyen)
- **IR** : 4×12 V30 ou mix V30/Creamback
- **Micro** : 57 (attaque) + 121 (corps)
- **Effets** : delay court + plate, reverb modérée

### 4.5 Modern hi-gain — “tight, précis”

- **NAM** : 5150/EVH / Rectifier / Diezel (selon goût)
- **IR** : 4×12 V30
- **Micro** : 57 on-axis puis adoucir si harsh
- **Effets** : gate plus strict, EQ post minimal

---

## 5) Méthode A/B sur un morceau (pour décider vite)

1. Mets la **piste de référence** (Spotify/YouTube) + ton son au casque/monitors
2. Joue **des phrases courtes** (riff / accord / bend) identiques
3. Compare selon 3 axes :
    - **Grain** (NAM)
    - **Couleur / présence** (IR)
    - **Tightness** (combo + gate + low cut)
4. Ne change **qu’un seul paramètre à la fois**
5. Stop quand tu es “dans la zone” (80/20) — le reste = jeu/mix

---

## 6) Comment documenter (pour réutiliser)

Pour chaque “son de chanson”, note :

- Référence : *chanson / artiste / live / album*
- Guitare + micros (humbucker/single)
- **NAM** : marque/modèle/canal/gain (nom exact)
- **IR** : pack + cab + HP + micro + placement (nom exact)
- Effets clés (OD, delay type, reverb)
- 1 phrase : “ce que ça reproduit” (ex : *attaque tranchante + médiums présents*)
